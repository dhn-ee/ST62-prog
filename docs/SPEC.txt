
1 ST62 machine cycle is 13 OSCIN clock cycles (T1-T13)

The document "ST62 & ST63 FAMILIES 8-BIT MICROCONTROLLERS OTP / EPROM
PROGRAMMING SPECIFICATION (Rev 3.2 October 1998)" uses the convention that
in target cpu cycle T1 input lsb is setup on TROMIN (latched on next clock) and
output lsb is driven on SDOP
